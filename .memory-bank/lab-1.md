# Лабораторная 1: Docker и Playwright-скрапер

## Цель

Упаковать приложение вместе со средой так, чтобы оно запускалось везде,
где есть Docker. Скраперу нужен Chromium с системными библиотеками;
тяжёлую браузерную среду нельзя скачивать заново при каждой правке кода.
Это же приложение будет использоваться в следующих лабораторных:
в облаке, на сервере и в кластере.

## Требуемый результат

- Скрапер на Playwright открывает https://quotes.toscrape.com/scroll
  в Chromium, получает цитаты, подгружаемые JavaScript, и записывает
  их в `out/result.json`. В исходном HTML этих данных нет.
- Один итоговый Docker-образ собирается multistage Dockerfile.
- Makefile содержит цели `build`, `run`, `clean`, `ci` и служит
  единственной точкой входа для команд проекта.
- GitHub Actions вызывает `make ci`.
- Открыт PR из `feat/quotes-scrapper` в `main`.

## Обязательные ограничения

- Базовый образ — `node:22-bookworm`.
- Готовые образы `mcr.microsoft.com/playwright` и аналоги запрещены:
  браузерную среду и системные библиотеки нужно установить самостоятельно.
- Если команды нет в Makefile, её не существует для рабочего процесса
  лабораторной. Ручных Docker-команд в терминале быть не должно.
- Каталог `out/` не коммитится в Git.

## Примерная структура из задания

```text
repo/
├─ Dockerfile
├─ Makefile
├─ src/
├─ package.json
├─ package-lock.json
├─ out/
└─ .github/workflows/ci.yml
```

Структура примерная; задание допускает аналоги файлов зависимостей
в зависимости от языка. Окончательный стек и устройство приложения
нужно зафиксировать как принятые решения, а не приписывать условиям.

## Definition of Done

1. Открыт PR из `feat/quotes-scrapper` в `main`; до защиты он не слит.
2. `make build` собирает образ.
3. `make run` создаёт в `out/result.json` непустой валидный JSON с цитатами.
4. `make clean` удаляет образ и `out/`; `git status` чистый.
5. Повторный `make build` после `make clean` не скачивает браузер заново.
6. Правка одной строки кода не вызывает повторную сборку браузера
   или установку зависимостей.
7. CI зелёный на последнем коммите PR и вызывает `make`.
8. В `README.md` есть короткое описание проекта, настройка локальной
   среды разработки и инструкции сборки продакшн-образа.
