# Quotes scraper

Лабораторная работа по Docker: скрапер на Node.js и Playwright Chromium открывает
[ленту цитат](https://quotes.toscrape.com/scroll), подгружает карточки прокруткой,
извлекает текст, автора и теги, удаляет повторы по паре текст/автор.
Результат сохраняется на хосте в `out/result.json`:

```json
[
  {
    "text": "Текст цитаты",
    "author": "Автор",
    "tags": ["example"]
  }
]
```

Порядок первого появления цитат сохраняется. Число записей не задано заранее.
Каталог `out/` не включается в Git и Docker build context.

## Локальная среда

Нужны Docker с запущенным daemon и GNU Make. На macOS можно использовать
Docker Desktop. Node.js, npm, Playwright и Chromium устанавливаются и работают
в контейнерах; установка этих компонентов на хост не требуется.

Сборке нужен доступ к Docker Hub, npm и источникам Debian/Chromium.
Запуску нужен доступ к сайту цитат. Локальные сборка и запуск проверены
на macOS arm64 с Docker Desktop; отдельный Linux-хост пока не проверен.

## Сборка и запуск

Все команды проекта выполняются из корня репозитория через Makefile:

```sh
make build
make run
```

Доступны только `build`, `run`, `clean`, `ci`, `lock` и `help`.
Справка выводится командой `make help` или просто `make`.

`build` собирает production-образ `quotes-scraper:lab1` из multistage Dockerfile
на `node:22-bookworm`. Chromium и системные библиотеки устанавливаются в образ
перед копированием исходников. `run` использует уже собранный образ, создаёт
локальный `out/`, монтирует его в контейнер и запускает скрапер с UID/GID
пользователя. После завершения контейнер удаляется автоматически. При отсутствии
образа сначала выполните `make build`.

Для изменения имени образа передавайте одно значение всем связанным командам:

```sh
make build IMAGE=quotes-scraper:local
make run IMAGE=quotes-scraper:local
make clean IMAGE=quotes-scraper:local
```

`package-lock.json` хранится в репозитории. После изменения зависимостей
перегенерируйте его в одноразовом Node-контейнере, затем пересоберите образ:

```sh
make lock
make build
```

## Очистка и кеш сборки

```sh
make clean
```

Удаляет образ с выбранным именем и локальный `out/`. Повторный вызов допустим.
Кеш сборщика и посторонние образы не удаляются; реальные ошибки Docker или
удаления файлов возвращаются вызывающей среде.

Для ручной проверки кеша выполните `make build` дважды, затем `make clean`
и `make build`. В plain-логах сборки установка
npm-зависимостей и Chromium с системными библиотеками должна иметь `CACHED`.
Затем добавьте одну временную строку-комментарий в `src/scraper.js` и повторите
`make build`: тяжёлые слои должны остаться в кеше. Удалите только свой комментарий
и снова выполните `make build`. Между замерами не меняйте зависимости, builder
или платформу. Сохраните существующие правки пользователя при эксперименте.

## CI и текущие ограничения

```sh
make ci
```

Цель последовательно собирает образ, запускает скрапер и проверяет результат
Node.js из собранного контейнера. Для проверки `out/` монтируется только для чтения.
Требуется непустой JSON-массив цитат: `text` и `author` — непустые строки,
`tags` — массив строк. Отсутствие файла, повреждённый JSON или неверные поля
приводят к ненулевому коду завершения.

Порядок сохраняется при `make -j ci`. Ошибка сборки или запуска останавливает
следующие шаги, ошибка проверки также возвращается вызывающей среде.
GitHub Actions запускает тот же `make ci` на `push` и `pull_request`.
